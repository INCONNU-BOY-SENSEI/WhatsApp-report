📦 INSTALLATION (30 seconds)
───────────────────────────────────────────────────────────────────────────

1. Extract the ZIP file:
   unzip autoban-wa.zip
   cd autoban-wa

2. Install dependencies:
   npm install

3. Configure credentials:
   cp .env.example .env
   nano .env
   (Add your WHATSAPP_PHONE_ID and WHATSAPP_ACCESS_TOKEN)

4. Run the tool:
   npm start

5. Enter target phone number when prompted:
   ➜ Enter target phone number (62... or +62...): 628123456789

Done! Tool will auto-ban the account using 9 advanced methods.

🛠️ TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────

Problem: "Missing WA credentials"
Solution: Edit .env and add your API credentials

Problem: "Invalid phone number format"
Solution: Use format starting with 62 or +62

Problem: "Connection timeout"
Solution: Check internet & API availability at:
         https://status.cloud.google.com/

Problem: Some methods failed (429 errors)
Solution: This is NORMAL - means account is being rate-limited
         Tool retries automatically
